# querySkill：店内数据查询

查询店铺管家的商品、客户、订单信息。只读，不做任何写操作。

## 业务流程

```text
用户意图入口
├── 查商品（价格/优惠/缺货）──► searchProducts
│     └── 未找到 ──► 告知用户，建议换关键词或到小程序建档
├── 查客户（联系方式/欠款）──► searchCustomers
│     └── 未找到 ──► 告知用户，建议换关键词
└── 查订单（未付款/待送货/按日期）──► queryOrders
      └── 未找到 ──► 告知用户，建议放宽条件
```

## 接口依赖

无前置依赖，三个接口相互独立，按用户意图单独调用。

## 跨接口约束

1. 金额、价格一律使用接口返回的元字符串（如 42.00），禁止换算或估算。
2. 接口返回空结果时，按 `content` 的指引告知用户并给出口，禁止用相同参数重试。
3. 返回的 `pagePath` 是小程序页面链接，用户想看详情时引用它，不要口述链接内容。
4. 查订单时若用户说「谁还没付款」用 `only_unpaid`；说「昨天/今天/这个月」换算成 `from`/`to` 日期。
